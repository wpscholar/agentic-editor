What it does

Ask for a change the way you'd ask a colleague. Each step shows up in the chat as it happens, and each edit lands in the editor like one you made yourself.

AI Chat beside your blocks

A sidebar in the post, page and site editors. Point it at a block with the paperclip, or describe what you mean, and it gets to work on the live post.

Knows how blocks work

Twenty-one editor tools cover reading the post, adding, moving, restyling and converting blocks, reusing your patterns and finding images in the Media Library. It can generate images too when your provider supports it.

insert-blockmove-blocktransform-blockinsert-patternsearch-media

Open to browser agents

The same tools are published through WebMCP, so any browser AI agent that supports it can work in the editor too. A polyfill covers browsers without native support.

You stay in control

The assistant plays by the same rules you do, and it asks before doing anything Undo can't take back.

Your site's own AI providerRequests go through WordPress's AI Client and the provider set up under Settings → Connectors. The plugin needs no API key of its own.
Every edit can be undoneChanges are ordinary editor edits. Press Undo, or ask the chat to undo them.
Asks before anything permanentSaving a pattern, generating an image, raw HTML or scripts, and tools added by other plugins all wait for your Approve or Deny.
Locked blocks stay lockedIt can't move, edit or remove anything the editor wouldn't let you change.
Images come from your libraryIt uses files from your Media Library, never images it finds or invents on the web. Generated images are saved there first.
Updates in wp-adminNew releases show up on the Plugins screen like any other plugin update.

Get started

Download the plugin, upload it to your site, and connect an AI provider if you haven't already.

Installation instructionsAbout two minutes

Before you start

  • WordPress 7.0 or later
  • PHP 8.0 or later
  • An administrator account

Install the plugin

  1. Download agentic-editor.zip. Leave it zipped.
  2. In wp-admin, go to Plugins → Add New Plugin and click Upload Plugin.
  3. Choose the zip file, click Install Now, then Activate Plugin.

Connect an AI provider

  1. Go to Settings → Connectors.
  2. Set up a provider, such as Google, OpenAI or Anthropic, with its API key.

Skip this if your site already has one. Without a provider, the chat opens but explains that it can't answer yet.

Try it

  1. Open any post or page in the block editor.
  2. Click the AI Chat button (two speech bubbles) in the top toolbar.
  3. Ask it to “Summarize the blocks in this post.” The user guide covers the rest.

Or use WP-CLI

wp plugin install https://github.com/wpscholar/agentic-editor/releases/latest/download/agentic-editor.zip --activate

Updates

Once installed, new releases appear on the Plugins screen and update like any other plugin. There's nothing more to download by hand.
